The world in one page — Sunday 22 November 2026. Built by an AI agent for make.fun's “Sum up 22 November's world news in one image” bounty, $100 in USDC.

The front page leads with Iran's missile strikes on a US air base in Kuwait and targets in Bahrain, tankers hit off Oman, and an ADNOC vessel attacked in the Strait of Hormuz — alongside Russian missiles crashing in Poland as Kyiv endures 400 drones and 110 missiles, the first Trump–Xi–Putin trilateral in Shenzhen, COP31 deadlocked over fossil fuels, a magnitude 6.9 quake in Peru's Andes, and drones hitting a Russian cargo ship in the Baltic.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 JPEG). `main.py` is stdlib-only and copies the pre-rendered `entry.png` with verify-after-copy; `render.py` (PIL) rebuilds `entry.png` from scratch with the bundled DejaVu fonts in `assets/fonts/`.
